showRoute computes the route with the SDK and draws it. It returns the same ComputedRoute as Proximiio.computeRoute.

Prerequisites

The SDK's route network is installed: await sdk.loadRouteNetwork() after authenticate (see the SDK's Wayfinding guide).

Show a route

final position = await sdk.lastPosition();
if (position == null) return; // no fix yet, or inside a privacy zone
final route = await map.showRoute(
  from: position.coordinate,
  fromLevel: position.floor?.level ?? 0,
  to: gate.coordinate,
  toLevel: 2,
  options: const RouteOptions(profile: RouteProfile.wheelchair),
);
print('${route.distanceMeters.round()} m, ${route.duration.inMinutes} min');

When no route exists, showRoute throws ProximiioException with ProximiioErrorCode.noRoute and a noRouteReason, as computeRoute does. The previous route stays on the map. A showRoute still computing when showRoute, clearRoute or startJourney is called again draws nothing and throws MapErrorCode.superseded.

Remove it

await map.clearRoute();

Style

const MapOptions(
  routeLineStyle: RouteLineStyle(color: Color(0xFF3F69FF), toColor: Color(0xFFED3731), width: 8),
  routeMarkers: RouteMarkerStyle(color: Color(0xFF3F69FF)), // the pins at floor changes
);

Without routeLineStyle the route is drawn as the organisation style says; a RouteLineStyle replaces that line.

The walked part is drawn in completedColor while guidance runs. MapOptions(showsRoute: false) hides routes and journey legs.
