Move the camera

await map.setCenter(const Coordinate(latitude: 24.4866, longitude: 54.6074), zoom: 19);
await map.setZoom(18);
await map.zoomBy(-1);
await map.fitCoordinates([entrance, gate]);
await map.showVenue();       // frame the whole venue
await map.recentre();        // follow the visitor again

All of them animate unless animated: false.

Read it

final camera = await map.cameraState();   // center, zoom, direction, mode

Modes

CameraModeBehaviour
followFollows the dot (default)
followWithHeadingFollows and turns with the heading
freeStays where it is

map.cameraMode holds the mode now. recentre(zoom:) uses MapOptions.recentreZoom (18.5) without a zoom.

Insets

Keep the camera's framing, the logo and the attribution clear of your UI, for example a bottom sheet:

MapOptions(contentInsets: MapContentInsets.safeAreaPlus(EdgeInsetsDirectional.only(bottom: sheetHeight)));
MapContentInsetsSpace kept free
safeArea()The device safe area (default)
safeAreaPlus(insets)The safe area plus insets
fixed(insets)Exactly insets
none()Nothing

First framing

initialFraming: InitialFraming.allFeatures (default) frames all venue features; legacyFirstFloor frames the first floor. map.cameraReady completes after it.
