Layers

const MapOptions(features: MapFeatures.venueDefaults());   // default: everything but the paths
const MapOptions(features: MapFeatures.only(MapLayerToggles(paths: true, baseTiles: false)));
const MapOptions(features: MapFeatures.none());

MapLayerToggles: paths, walls, shops, pois, amenities, baseTiles.

Amenity icons

MapOptions(amenities: false) hides the amenity icons of POIs.

Hide features

Hide features the app draws differently, for example a selected POI shown with your own marker:

await map.setHiddenFeatureIds({selectedPoi.id});

Taps

map.featureTaps.listen((tap) async {
  if (tap.featureIds.isEmpty) return;
  final features = {for (final f in await sdk.features()) f.id: f};
  final poi = features[tap.featureIds.first];
  showPoiSheet(poi?.title());
});

A tap reports the ids of the venue features under it and its coordinate. The features themselves come from sdk.features().
