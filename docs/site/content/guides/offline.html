A dropout

Nothing to configure. The style is stored on the first load and the SDK stores the venue features, so a running map keeps drawing without a connection. Positions computed on the phone (BLE, phone-native UWB) do not need a connection; venue-side positions (BlueIoT AoA, BlueIoT UWB) arrive through the relay and stop without one.

A start without a connection

After one earlier run, the map draws the stored style and venue at once (styleSource is cache). Without an earlier run there is no stored style; the map opens the fallback style, which itself needs a connection, and shows only the dot.

The SDK's authenticate needs a connection. Plan the app's offline start with the SDK's Offline and sync guide.

An offline package

An installed offline package provides the style without any network access:

const MapOptions(offlinePackageId: 'terminal-1');

Install the package from a bundled seed with the SDK's installOfflineSeed first; syncOfflinePackage cannot fill a package in this release. Offline map tiles are not supported yet.

offlinePackageId is read when the map starts. When the package cannot be read, lastError says so and the map loads the style from the API; styleSource is offlinePackage only while the package style is shown.
