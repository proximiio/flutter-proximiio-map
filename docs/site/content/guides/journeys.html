A journey is a list of stops the visitor walks in order. JourneyNavigator routes each leg, draws it, follows the visitor, reports reached and passed stops, and reroutes after a deviation.

Build a journey

const journey = Journey([
  JourneyStop(id: 'atrium', title: 'Atrium', coordinate: Coordinate(latitude: 24.4866, longitude: 54.6074), level: 0),
  JourneyStop(id: 'gallery-3', title: 'Gallery 3', coordinate: Coordinate(latitude: 24.4871, longitude: 54.6081), level: 1),
]);

// Or from a journey edited in the Map Editor:
final tours = await sdk.journeys();
final fromEditor = Journey.fromProximiioJourney(tours.first);

Journey.toJson and Journey.fromJson store a journey, for example to resume it after a restart.

Start it

final navigator = await map.startJourney(
  journey,
  rules: const JourneyRules(advanceOnDepartureMeters: 8),
  routeOptions: const RouteOptions(profile: RouteProfile.wheelchair),
);

With advanceOnDepartureMeters the navigator moves to the next stop once the visitor walks that far from a reached one; without it, call navigator.advance(). One journey runs per map; starting another replaces it.

State

ValueListenableBuilder(
  valueListenable: navigator.state,
  builder: (context, state, _) {
    if (state == null) return const SizedBox.shrink();
    return Text('${state.activeStop?.title}: ${state.overview.activeLegRemainingMeters?.round()} m, '
        '${state.overview.remainingStopIds.length} stops left');
  },
)

JourneyState holds the journey with each stop's state (pending, active, reached, done, skipped), the overview of distances and times, the deviation while off route, and the stops no route leads to. navigator.guidance is the guidance of the active leg.

Events and cues

navigator.events.listen((event) {
  switch (event) {
    case JourneyStopReached(:final stop):
      showStopCard(stop);
    case JourneyLeftRoute(:final distanceMeters):
      log('off route by $distanceMeters m');
    case JourneyFinished():
      showSummary();
    default:
      break;
  }
});
navigator.cues.listen((cue) => speak(cue.text));

Change the plan

CallEffect
advance(), skip()Next stop; skip the active one
markDone(id), skipStop(id), reopen(id), activate(id)Change one stop
detour(stop), cancelDetour()Walk to another place first
addStop, insertStop, removeStop, replaceStop, moveStopEdit the stops
update(journey)Replace the journey, keeping progress
setRouteOptions(options)Route the remaining legs differently
resumeJourney()Resume after a detour or deviation

Reorder

final proposal = await navigator.proposeOrder(pinnedStopIds: {'exit'});
if (proposal != null && proposal.savedMeters > 50) {
  await navigator.apply(proposal);
}

replanFromHere() proposes an order from the visitor's position. apply returns false when the journey changed since the proposal.

Camera

fitActiveLeg() and fitJourney() frame the leg or the whole journey.

End it

await navigator.end();

Removing the map widget ends the journey too.
