The map draws the position of the SDK instance itself: a dot, an accuracy ring and a heading beam. No Dart code feeds it. The dot appears after sdk.requestPermissions() grants location and sdk.start() runs.

Heading

HeadingModeThe dot points to
courseThe direction of movement (default)
compassThe compass
noneNothing; no beam

To point it from your own source: map.setHeading(degrees); setHeading(null) returns to the mode.

Trail

const MapOptions(trail: MapTrail.lastMinutes(2));   // or MapTrail.lastFixes(30)

map.clearTrail() removes the trail drawn so far.

Following

With CameraMode.follow (default) the camera follows the dot; with followWithHeading it also turns with the heading. map.recentre() follows the visitor again after the user moved the map.

Privacy zones

Inside a privacy zone the dot stays on the last fix from before the zone, in grey, without the heading beam. Guidance and journeys take no positions there. ProximiioConfiguration.withholdsPositionsInPrivacyZones (default true) also withholds them from sdk.positions and sdk.lastPosition().
