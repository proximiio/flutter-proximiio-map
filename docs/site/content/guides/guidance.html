With guidance on, the map follows the visitor along the route from showRoute and reports the next manoeuvre, the distance to it and the distance left.

Turn it on

await map.showRoute(from: here, fromLevel: 0, to: goal, toLevel: 0);
await map.setGuidanceRules(RouteFollowRules.venueWalk);

ValueListenableBuilder(
  valueListenable: map.guidance,
  builder: (context, guidance, _) => Text(guidance?.text ?? ''),
)

setGuidanceRules(null) turns it off.

What guidance reports

FieldMeaning
manoeuvre, nextManoeuvreRouteManoeuvre: kind (turnLeft, levelChange, arrive, …), position, level
distanceToManoeuvreMetersDistance to the next manoeuvre
remainingMeters, traveledMetersDistance left and walked
isOffRoute, offRouteMetersThe visitor left the route
hasArrived, arrivalProgressArrival, and its confirmation from 0 to 1
textThe instruction as a sentence

map.instructionText(destinationTitle: 'Gate B12') returns the current sentence with the destination's name on arrival.

Text languages

Instruction text exists in English and Arabic. It follows MapOptions.language; other languages get English. Build your own text from manoeuvre.kind for other languages.

Rules

PropertyDefaultPurpose
arrivalRadiusMetersfrom accuracy, 3–10 mDistance that counts as arrived
arrivalDwell2 sTime within the radius before arrival
offRouteMeters12 mDistance from the route that counts as off route
offRouteFixes3Positions in a row beyond it

Off route

The map does not reroute by itself. When isOffRoute turns true, call showRoute again from the current position. Journeys reroute on their own; see Multi-stop journeys.
