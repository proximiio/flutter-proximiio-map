The map shows "Call Proximiio.create(...) before showing the map"

The widget was built before the SDK instance existed. Await Proximiio.create before building ProximiioMap.

The map shows "needs Flutter's Swift Package Manager support"

The iOS app builds plugins through CocoaPods. Run flutter config --enable-swift-package-manager.

Only the dot, no venue

  • styleSource is fallback: the organisation style could not be loaded. Check the connection and the token's host.
  • lastError names the failure.
  • features: MapFeatures.none() hides the venue.

showRoute throws noRoute / emptyNetwork

The SDK's route network is not installed: call sdk.loadRouteNetwork() after authenticate.

The map does not pan inside a scroll view

Custom gestureRecognizers without an eager recognizer let the scroll view win. Leave the parameter out, or include EagerGestureRecognizer.

Android: the map stutters while scrolling Flutter content

An opaque MapOptions.backgroundColor switches the map to a SurfaceView. Leave it transparent.

iOS: two MapLibre versions

The iOS map pins MapLibre 6.29.0 exactly. Another plugin that brings a different MapLibre version cannot resolve with it.
