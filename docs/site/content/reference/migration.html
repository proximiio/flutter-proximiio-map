Version 1.x showed the Proximi.io web map in a WebView and passed the token to the widget. Version 6.0 shows the native iOS and Android map in a platform view, on the SDK instance of flutter_proximiio. There is no compatibility layer.

Steps

  1. Update both packages to the pair from Versioning and releases, and follow the flutter_proximiio migration guide.
  2. Remove webview_flutter if nothing else uses it.
  3. On iOS, turn on Swift Package Manager (Installation).
  4. Replace the widget and the calls with the table above.
