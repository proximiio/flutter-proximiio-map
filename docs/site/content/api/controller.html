One controller per map, from ProximiioMap.onMapCreated. Methods return Futures.

MemberType

Methods

MethodPurpose
setOptions(MapOptions)Replace the options
cameraState()MapCameraState: center, zoom, direction, mode
setCenter(coordinate, {zoom, animated}), setZoom, zoomBy, fitCoordinatesMove the camera
recentre({zoom, withHeading}), showVenue()Follow the visitor; frame the venue
setHeading(degrees)Point the dot; null returns to MapOptions.heading
selectFloor(level), followMyFloor()Floors
setHiddenFeatureIds(ids), clearTrail()Features, trail
showRoute({from, fromLevel, to, toLevel, options}), clearRoute()Routes; returns ComputedRoute
setGuidanceRules(rules), instructionText({destinationTitle})Guidance
startJourney(journey, {rules, routeOptions})Start a journey; returns JourneyNavigator
dispose()Release the map; the widget calls it

Errors

Route failures are ProximiioExceptions with ProximiioErrorCode.noRoute. Everything else throws ProximiioMapException:

MapErrorCodeMeaning
notConfiguredNo SDK instance when the map was created
notReadyThe map was disposed
noJourneyA journey call without a running journey
unknownProposalThe proposal was applied already or is unknown
invalidArgumentA value was rejected
unsupportediOS without Swift Package Manager
underlyingAnother failure in the map library
unknownA code added after this release
