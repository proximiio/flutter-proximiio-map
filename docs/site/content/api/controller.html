Errors

Route failures are ProximiioExceptions with ProximiioErrorCode.noRoute. Everything else throws ProximiioMapException:

MapErrorCodeMeaning
notConfiguredNo SDK instance when the map was created, or Proximiio.create replaced it
notReadyThe map was disposed, also during the call
noJourneyA journey call without a running journey
unknownProposalThe proposal is unknown or was applied already
supersededA later showRoute, clearRoute or startJourney replaced the route call; nothing was drawn
invalidArgumentA value was rejected (Android; iOS reports rejected values as underlying)
unsupportediOS without Swift Package Manager
underlyingAnother failure in the map library
unknownA code added after this release
