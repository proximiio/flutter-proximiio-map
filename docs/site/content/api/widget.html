const ProximiioMap({
  Key? key,
  MapOptions options = const MapOptions(),
  void Function(ProximiioMapController controller)? onMapCreated,
  Set<Factory<OneSequenceGestureRecognizer>>? gestureRecognizers,
  Widget placeholder = const SizedBox.expand(),
})
ParameterPurpose
optionsHow the map looks and behaves; see MapOptions
onMapCreatedCalled once with the controller when the native map exists
gestureRecognizersGestures the map takes before the widgets around it; null takes every gesture
placeholderShown until the platform view is created

Options

  • A changed options value is sent to the map, also one set before the platform view exists. A rebuild with equal options sends nothing.
  • offlinePackageId and initialFraming apply only to a new map.
  • backgroundColor: iOS applies a change at once; Android applies it to a new map.

Lifecycle

  • Create the SDK with Proximiio.create before the widget is built. Without it the map shows a notice and cameraReady fails with MapErrorCode.notConfigured.
  • The map follows stop() and start() of its SDK instance. After Proximiio.create replaced the instance, rebuild the widget with a new Key.
  • Removing the widget releases the native map, also when its platform view was never created. Controller calls then throw MapErrorCode.notReady.
  • iOS and Android only; on other platforms the widget shows a message.
