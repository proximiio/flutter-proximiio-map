const ProximiioMap({
  Key? key,
  MapOptions options = const MapOptions(),
  void Function(ProximiioMapController controller)? onMapCreated,
  Set<Factory<OneSequenceGestureRecognizer>>? gestureRecognizers,
  Widget placeholder = const SizedBox.expand(),
})
ParameterPurpose
optionsHow the map looks and behaves; a changed value updates the map
onMapCreatedCalled once with the controller when the native map exists
gestureRecognizersGestures the map takes first; default all
placeholderShown until the platform view is created

Lifecycle

  • Create the SDK with Proximiio.create before the widget is built.
  • The controller is valid until the widget is removed; then the native map is released and calls throw MapErrorCode.notReady.
  • iOS and Android only; other platforms show a message.
