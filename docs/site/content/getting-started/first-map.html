Prerequisites

  • flutter_proximiio set up and an application token.
  • An SDK instance from Proximiio.create, authenticated, before the map is shown.

Show the map

class VenueMapPage extends StatefulWidget {
  const VenueMapPage({super.key});

  @override
  State<VenueMapPage> createState() => _VenueMapPageState();
}

class _VenueMapPageState extends State<VenueMapPage> {
  ProximiioMapController? _map;

  @override
  Widget build(BuildContext context) => Scaffold(
    body: ProximiioMap(
      options: const MapOptions(floorSelector: FloorSelectorPosition.trailing),
      onMapCreated: (controller) => setState(() => _map = controller),
    ),
  );
}

The widget creates the native map, then calls onMapCreated once with its controller. Removing the widget releases the map.

Read the map's state

State the map changes by itself is exposed as ValueListenables:

ValueListenableBuilder(
  valueListenable: map.selectedFloor,
  builder: (context, floor, _) => Text('Floor ${floor.level}'),
)
ListenableValue
floorsThe venue's floors
selectedFloorThe floor shown and whether it is pinned
cameraModefree, follow, followWithHeading
styleSourceWhere the style came from
guidanceTurn-by-turn progress
lastErrorThe last loading error, for display

featureTaps is a stream of taps; cameraReady completes when the camera first framed the venue.

Change the options

Rebuild the widget with new options, or call map.setOptions(...). Equal options are not sent again.
