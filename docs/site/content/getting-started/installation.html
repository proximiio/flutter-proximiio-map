The map package depends on flutter_proximiio. Set up that plugin first; its installation guide covers the SDK repositories, Info.plist keys, the iOS scene lifecycle and the Android build settings the map needs too. The map works with either iOS lifecycle.

Add the packages

dependencies:
  flutter_proximiio:
    git:
      url: https://github.com/proximiio/flutter-proximiio
      ref: 6.0.0-beta.1
  flutter_proximiio_map:
    git:
      url: https://github.com/proximiio/flutter-proximiio-map
      ref: 6.0.0-beta.1

Use the pair of versions from Versioning and releases.

iOS

The iOS map library ships only as a Swift package. Turn on Flutter's Swift Package Manager support:

flutter config --enable-swift-package-manager

The plugin's package then pulls proximiio/proximiio-map-ios-binary and the SDK. Minimum iOS 15.

Built through CocoaPods, the plugin compiles, but every map shows a notice instead of the map and each controller call throws MapErrorCode.unsupported.

The iOS map pins MapLibre at exactly 6.29.0. An app that also uses another MapLibre plugin must use the same MapLibre version.

Android

The map comes from https://maven.eu.proximi.fi/releases/, the repository the SDK uses. The build settings of flutter_proximiio apply: minSdk 26, compileSdk 37, Android Gradle Plugin 8.13, Kotlin 2.2.

Verify

Run the example app: in example/, copy env.example.json to env.json and set PROXIMIIO_TOKEN (and PROXIMIIO_API_BASE_URL for another API host), then run flutter run --dart-define-from-file=env.json. The venue appears with the floor picker on the right.
