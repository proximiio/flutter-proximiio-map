The map draws the organisation's MapLibre style from the Proximi.io API. The style is read through the SDK and stored on the device.

Sources

MapStyleSourceMeaning
pendingLoading
cacheThe style stored on an earlier run
organizationThe organisation's style from the API
offlinePackageThe style of an installed offline package (MapOptions.offlinePackageId)
fallbackThe organisation style could not be loaded; the map shows MapOptions.fallbackStyleUrl
 
ValueListenableBuilder(
  valueListenable: map.styleSource,
  builder: (context, source, _) => source == MapStyleSource.fallback
      ? const Text('Venue map unavailable')
      : const SizedBox.shrink(),
)

The credential

Tiles, glyphs and sprites from the API host are requested with the application token as an Authorization header. The token never appears in a URL or in the stored style.

Changes

When the organisation's style changes, the map loads the new style. A refresh that returns the same style does not reload the map.
