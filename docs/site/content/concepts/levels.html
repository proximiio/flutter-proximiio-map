The map shows one floor at a time. By default it shows the visitor's floor and follows it. When the user or the app chooses a floor, that floor is pinned until the app follows the visitor again.

Levels

A floor is identified by its level, a double. Intermediate levels such as a 1.5 mezzanine are kept.

State

map.floors.value          // List<MapFloor>: level and name
map.selectedFloor.value   // MapFloorSelection: level shown, isPinned

A floor's name can arrive after its level; the list is updated when it does.

Pinning

await map.selectFloor(2);    // show level 2, stop following the visitor's floor
await map.followMyFloor();   // follow the visitor's floor again

A floor picker

The built-in picker: MapOptions(floorSelector: FloorSelectorPosition.trailing). Your own:

ValueListenableBuilder(
  valueListenable: map.floors,
  builder: (context, floors, _) => ValueListenableBuilder(
    valueListenable: map.selectedFloor,
    builder: (context, selected, _) => SegmentedButton<double>(
      segments: [for (final f in floors) ButtonSegment(value: f.level, label: Text(f.name ?? '${f.level}'))],
      selected: {selected.level},
      onSelectionChanged: (levels) => map.selectFloor(levels.first),
    ),
  ),
)
