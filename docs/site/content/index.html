Proximi.io Flutter map v6

The venue map, floors, routes, guidance and journeys, as one Flutter widget.

flutter_proximiio_map shows the native Proximi.io Map v6 for iOS and Android as a Flutter platform view. It draws the organisation's style, the visitor's position and floor from flutter_proximiio, routes, turn-by-turn guidance and multi-stop journeys.

The platform view Native map inside Flutter: gestures, composition, lifecycle. Routes and guidance Show a route and follow it with turn-by-turn instructions. Multi-stop journeys Tours and visit plans with stops, detours and reordering. API reference The widget, the controller, the options and the journey types.

The shortest integration

final sdk = await Proximiio.create(ProximiioConfiguration(token: token));
await sdk.requestPermissions();
await sdk.authenticate();
await sdk.start();

// In a widget tree:
const ProximiioMap(options: MapOptions(floorSelector: FloorSelectorPosition.trailing));

The map uses the SDK instance Proximiio.create made. Create it before the map; the map then shows the venue, the position dot and the floor of that instance.
